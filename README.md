About the Project

This project is an Online Course Analysis Dashboard created using Microsoft Excel and Power BI. The goal of the project is to analyze online course data and turn raw data into meaningful insights through data cleaning, pivot tables, charts, KPIs, and interactive visualizations.

I worked on the data preparation and analysis in Excel and then used Power BI to create an interactive dashboard for exploring the data more easily.

Tools Used
Microsoft Excel
Power BI
Power Query
Pivot Tables
Pivot Charts
Excel Workflow

The Excel file is organized into four main sheets:

1. Raw Data

Contains the original dataset before making any changes or cleaning.

2. Cleaned Data

The data was cleaned and structured to make it suitable for analysis and visualization.

3. Pivot Tables

Created pivot tables to summarize the data and analyze different aspects of the courses.

4. Pivot Charts

Created charts from the pivot tables to visually understand trends and comparisons.

Power BI Dashboard

The cleaned data was also used in Power BI to create an interactive dashboard. The dashboard includes KPIs, charts, and filters that allow users to explore the course data and identify important patterns.

Some of the analysis includes:

Total number of courses
Paid vs free courses
Average course price
Course reviews and subscribers
Course duration
Category/course-level analysis
Project Workflow

Raw Data → Data Cleaning → Pivot Tables → Pivot Charts → Power BI Dashboard
